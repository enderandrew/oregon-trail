# The Oregon Trail

#### Exactly As You Rememer It (Except Not At All)

## Description

I forked something I found here on Github made 8 years ago by Nate Cottle, Ryan Putman, Will Swanson, Reese Glasscock, but it was Bootstrap and jQuery. I gutted that. The wagon moved and the canvas didn't. There were no landmarks and no real features. I ended up rewriting the whole thing. Maybe 1% of the original project remains.

I wanted to create something that appealed to the nostalgia of the original Oregon Trail game, but had deeper gameplay and tons of jokes.
